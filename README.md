## 📖 About

**ToyJoy** is a modern toy e-commerce website designed to provide a smooth and engaging shopping experience. It features a clean user interface, responsive design, fast performance, and intuitive navigation for users across all devices.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/ToyJoy.git
```

### Go to Project

```bash
cd ToyJoy
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
